## 如何转移

将整个交接目录或 ZIP 复制到另一台电脑并解压。文件之间使用相对链接，无需保持原电脑盘符。

源码仓库：<https://github.com/lzx0215/ReportDesk>

生成交接包时的本地基线：

```text
分支：main
HEAD：e54c88ffc6416911eaf6e3a62729b057b2a05552
标签：v0.3.0
提交说明：Merge branch 'codex/release-v0.3.0-finalize'
整理方案前：工作区干净，本地 main 与已缓存 origin/main 对齐
本轮没有 fetch/pull；不声称已核实远端实时状态
```

建议在新目录克隆，避免覆盖另一台电脑已有工作：

```powershell
git clone https://github.com/lzx0215/ReportDesk.git ReportDesk-Web
Set-Location ReportDesk-Web
git switch -c codex/web-iis-plan e54c88ffc6416911eaf6e3a62729b057b2a05552
git status --short --branch
```

这是复现本次方案基线的命令。若后续选择更新的代码，应先检查差异并更新基线记录。交接文档本轮未提交、未推送，单独克隆仓库不保证得到本交接包，务必同时复制 ZIP。

本包不含 ReportDesk 源码全量副本、HIS 二进制、真实报表 XML、数据库凭据、患者数据或数据库导出。无外网的开发电脑需另行准备经允许转移的源码和依赖；这里不把完整 HIS LIB 当成网页运行依赖。
