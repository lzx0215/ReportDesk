# 内网验收清单

本文件记录的是尚需内网执行的验收，不是已通过结果。每项实际执行后填写日期、环境、状态和证据；不记录患者明细或密码。

| 场景 | 状态 | 成功标准 |
|---|---|---|
| Windows 10 32 位 + .NET 4.8 启动 x86 包 | NOT RUN | 无缺失 DLL/平台错误，界面完整 |
| Windows 10 64 位 + .NET 4.8 启动 x64 包 | NOT RUN | 同上；常见 DPI/分辨率下按钮可操作 |
| Oracle 19c 正确 Service Name 与只读账号 | NOT RUN | 正常连接并执行小范围查询 |
| TNS 文件 + Service Name 别名（x86/x64） | NOT RUN | 选择别名后连接预期数据库，小范围查询成功 |
| TNS 文件 + SID / 多地址 / DESCRIPTION_LIST | NOT RUN | 按现场实际配置连接，服务身份与重试行为符合预期 |
| TNS 别名变更、文件移动、缺失别名 | NOT RUN | 重新读取正确；错误配置明确失败，不连接其他来源 |
| 直接连接与 TNS 切换、保存后重开 | NOT RUN | 服务器值保留，所选路径及别名恢复，旧目录仍可读取 |
| TNS 不可达、多地址超时、取消 | NOT RUN | 界面不冻结；握手等待与配置一致，执行阶段可请求取消 |
| 常规/高级连接设置（Win10 x86/x64，常用 DPI） | NOT RUN | TNS 时仅显示网络服务字段；基本模式可填写主机/端口/服务名；按钮可操作 |
| 内网环境变量/注册表的 TNS 自动发现 | NOT RUN | 加载预期文件；多文件需明确选择来源，无文件可手动浏览 |
| 测试连接：正确账号、错误密码、网络不可达 | NOT RUN | 正确账号登录成功并释放连接；失败清楚提示且不显示密码；不自动保存 |
| 测试过程中关闭窗口 | NOT RUN | UI 可关闭；握手按网络配置返回后释放会话，不写入报表数据 |
| 连接名和旧版设置升级 | NOT RUN | 保存名称并重开恢复；原直接/TNS 设置及密码保存选择保持 |
| 错误密码、不可达地址、错误 Service Name | NOT RUN | 清楚报错，不泄露密码，不无限等待 |
| 日期起止边界与空值 | NOT RUN | 与 HIS 同条件的边界记录一致 |
| 科室/当前操作员参数 | NOT RUN | ID 取值及可查询范围符合现场授权，无扩大范围 |
| 字典选项、ALL、项目 ID | NOT RUN | 名称对应正确 ID，ALL 含义与原 SQL 一致 |
| 普通主表 | NOT RUN | 列值、行数、金额与 HIS 一致 |
| 主表、明细和合计数据源 | NOT RUN | 各自同条件结果一致；理解不会自动生成模板合计 |
| 超时、执行中取消、网络中断 | NOT RUN | 客户端可恢复，服务端请求停止情况经过核查 |
| 超过原 50000 行/32 MiB、查询超过原 60 秒 | NOT RUN | 不因旧应用限额提前终止或截断；行数与现场基准一致 |
| 手动取消长查询、内存不足、网络断开 | NOT RUN | 可请求取消；失败不显示部分结果为成功；错误日志可定位原因 |
| 连接等待超过原 10 秒 | NOT RUN | 不因程序旧限额终止；外部超时需结合 TNS/数据库/网络核实 |
| 连接/查询/导出/导入报错日志 | NOT RUN | 主窗口可打开日志；含时间/错误码/堆栈，无凭据/SQL/参数/结果明细 |
| 日志目录不可写、磁盘空间不足 | NOT RUN | 明确提示日志未写入；仍保留原始操作失败信息 |
| Excel / WPS 打开 xlsx | NOT RUN | 中文、前导零、长编号、金额、日期、空值均正确 |
| 反复查询后切换报表/数据源 | NOT RUN | 无上次结果被误认为本次结果，无重复执行 |
| 更新、收藏、验证状态重置 | NOT RUN | 原定义变化后重置核对状态，个人说明保留 |
| 只读账号对象与函数权限审核 | NOT RUN | 不授予写权限；调用函数无未经授权副作用 |

已知限制：此版是报表检索与所选 SQL 数据源试查工具，不是原 HIS 报表渲染器。静态可试查不等于生产可用。
