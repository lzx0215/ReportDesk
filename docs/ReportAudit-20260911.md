## 已确认的误拦截

中医住院病案医嘱接口标准查询设置.xml:24、26 的 TRUNCATE 属于 LISTAGG ON OVERFLOW TRUNCATE，不是清表语句。参见 [Oracle 19c LISTAGG](https://docs.oracle.com/en/database/oracle/oracle-database/19/sqlrf/LISTAGG.html)。本轮统计列出解析器修复方向，未改变 SQL 执行规则或业务口径。
