# 报表列同步：使用与验收边界

## 使用

1. 连接测试数据库，选择报表并填写查询条件。
2. 打开「SQL 编辑」，修改 SELECT 字段；新增字段建议使用明确、唯一的别名，例如 `AS "申请医生"`。有 UNION 时须自行补齐每个分支。
3. 点「同步报表列」。程序用当前连接、绑定条件分别描述原 SQL 和新 SQL 的列信息（Oracle `SchemaOnly`），不加载明细行，不用字符串拆分 SELECT。SQL 已先保存、模板尚未补齐时也可同步，匹配规则见下文。
4. 核对查询路径、模板路径以及预览中的列。主模板通过文件命名约定定位，只是候选；还会检查模板的数据源 Tag 和列数。最终须由操作者确认模板归属。
5. 新列默认表头为字段名/别名；旧表头、隐藏状态保持。可改表头和列宽（24–1000）。位置与 SQL 的返回字段顺序一致：需要改变新增列位置时返回修改 SQL 后重新识别，不允许只移动表头造成数据错位。
6. 点击「确认并保存两份 XML」，在原生对话框确认两个目标路径。只写内容发生变化的文件；SQL 已保存且未继续修改时，不重写查询 XML。取消不会写文件；返回 SQL 编辑保留 SQL 草稿，但丢弃本次列设置。
7. 保存成功后查询定义重新加载，旧结果失效。外部已打开的 XML 须重新加载。到 HIS 检查数据显示、明细跳转和打印。

不改 SQL 时也可通过同步预览修改已有表头、列宽。数据库描述失败（语法、权限、参数或连接问题）会停止，不修改 XML。新 SQL 增加未定义的查询参数时，须先通过原配置工具补齐查询条件；本功能不修改条件定义。

## 第一版支持与拒绝范围

- 单工作表、首列数据源 Tag、普通单行表头；允许顶部整行合并标题。
- 原查询字段与模板列数一致时，原字段须保持顺序和名字，新字段可以在开头、中间或末尾插入。SQL 已保存导致字段多于模板列时，按下述规则恢复原列对应关系。
- 保留已有隐藏列，不把内部关联字段自动变成可见列；新增列为可见。
- 更新列数量、列宽、单元格位置、相关样式、标题合并宽度和选中位置。新增列继承邻近可见列的单元格字体、边框等样式，不复制数据、公式或类型专用 CellType/Formatter。
- 支持主表，以及能通过 XML 明细引用唯一定位且结构符合上述规则的明细模板；同用途存在多个数据源时拒绝。
- 拒绝重名字段、删除/重命名/重排旧字段、交叉/列合计/分组规则、多层或局部合并表头、冻结列、公式、自定义打印设置、图形图表、模糊文件匹配及来源链接。
- **普通会诊及时完成率**具有局部合并表头，当前会明确拒绝自动同步；本次已验证拒绝且原文件未变。它的复杂模板适配不在第一版范围。
- 预览展示的是列结构，不是 FarPoint 渲染或 HIS 打印排版。页面宽度、分页等不自动重设计。

## SQL 已保存时补齐模板

1. 不必撤销已保存的 SQL，直接点「同步报表列」。程序先验证 SQL 在当前数据库能够识别字段；不会修复 SQL 语法、GROUP BY 或改变统计口径。
2. 模板每个原表头（包括隐藏列）必须非空，且能与已保存 SQL 的字段名唯一对应，忽略大小写，原列顺序必须一致。不按“前 N 个字段”猜测，因此支持开头、中间和末尾已保存的新增字段。
3. 预览标注「SQL 已保存、模板待补齐」、每列的原位置以及新增列。核对后确认，才会补齐模板。已有表头、列宽和隐藏状态保留；新增表头默认取字段名。
4. 自定义表头与字段名不同、表头重复/缺失/顺序不一致等无法可靠对应的情况仍会拒绝。复杂模板限制不变。已保存字段不能在本次草稿中删除、重命名或重排；可以继续增加新字段。
5. 仅补模板时，查询 XML 的字节和修改时间保持不变；不生成备份。再次同步不重复加列。

## 保存和安全边界

- Renderer 不提供写入路径。Host 用已打开查询会话和服务端匹配的模板生成一次性预览令牌；保存重新验证会话、SQL、数据源、预览令牌、列序号及文件哈希。
- 两份文件全部准备、编码验证和冲突检查通过后，仅对内容发生变化的文件写同目录临时文件，再直接替换原文件，不生成 `.bak`；未变化的文件仍检查冲突并回读核对。原 SQL 文件只修改当前 SQL 内容；模板保持原编码/BOM及未涉及内容的 XML 语义，不承诺模板逐字节格式不变。
- 写完回读比对两份文件；保存中途失败会在目标仍等于本次写入内容时，用内存中的原字节撤回，绝不撤销外部修改。恢复不完整时明确报警并禁止继续用旧报表定义查询。
- 这不是两个文件的原子事务。断电/进程被强制终止可能留下不一致文件；不生成持久备份，也不承诺崩溃恢复。不要与 HIS 模板设计器等其他程序同时编辑。
- 数据库字段识别仍遵守现有绑定和只读 SQL 限制，非池化只读事务不能替代数据库最小权限。运行时使用用户选择的连接；自动测试强制 loopback，不连接原配置中的其他地址。
