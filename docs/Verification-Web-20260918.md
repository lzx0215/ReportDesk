# ReportDesk Web 首版实现与离线验证

日期：2026-09-18。实现依据：[内网简化方案](ReportDesk-Web-IIS-Minimal-Plan-20260918.md)。这是本地实现交付，不是生产上线或 HIS 等价验收结论。院内 HTTP 白名单是后续增量，见 [Verification-Web-IntranetHttp-20260918.md](Verification-Web-IntranetHttp-20260918.md)；下文浏览器与 IIS 结果不得冒称该增量已实测。

## 实现范围

一个 net48 Web 项目、一个 IIS 站点，沿用 Core 和 Host 业务逻辑，不引入新生产 NuGet 包。查询 `/` 免登录；维护 `/admin` 与 `/api/admin/*` 同时校验实际连接 IP，默认清单为空。没有账号平台、Redis、独立服务或长期报表版本库。桌面端保留。

| 原清单 | 本版落地与验证边界 |
| --- | --- |
| F01–F04 | 受控工作目录/单 XML 导入、记忆来源、新增检查、无 SQL 过滤、失效提示沿用 Host；不允许浏览任意服务器路径。真实 LIB 导入与元数据检查通过。 |
| F05–F08 | 搜索、说明、位置、适配状态保留；普通页关联摘要不泄露路径，维护页可看完整关联诊断。未知 HIS 菜单不推测。 |
| F09–F10 | Web 全员同一目录，桌面显示清单不变；静态复核和单报表重载保留。 |

| F42–F45 | 直连/TNS、服务器登记来源、别名、连接测试/保存、密码记忆开关保留；密码只写不回显，服务身份 DPAPI，不接受浏览器本机路径。真实连接、服务身份重启解密未测。 |

| F49–F51 | Web 不开放演示执行；旧 WinForms 独有内容留在旧客户端，不新增 Electron 原本没有的设计器、完整打印或自动主明细联动。 |
| 新增同步 | 读取发布表、解压/路径/XML/配套校验、自动纳入可识别新报表、幂等与晚提交复核、最新完整版本选择、本地冲突确认、失败回滚及进程中断恢复。无需执行 HIP；默认禁用，真实发布 BLOB 未验证。 |

页面复用而非重新设计；可见控件 ID 与现有桌面模板对照通过。导入、编辑只对服务器工作副本操作，不写原知识库或 HIS 发布表。

- 目标服务器 IIS 启停、预加载无人访问同步、回收交接、HTTPS、IP/代理边界、服务账号 DPAPI 与目录权限：NOT RUN。本机没有 IIS/IIS Express，预编译不能替代这些验证。
- 真实 Oracle 连接/查询/选项/SchemaOnly、现场两台电脑的真实结果与 HIS 同条件对照：NOT RUN。没有制造患者结果或以离线检查宣称 HIS 等价。
- 真实发布表 owner/字段、DIRECTORY_FLAG、相对路径、压缩 BLOB 与发布文件哈希：NOT RUN。现场样本确认前 `SyncSampleValidated=false`，不会建立同步连接。
- 同步仍是每轮全量读取历史 BLOB，未实现元数据缓存与周期全内容复核组合；启用前测读取成本，确定合适间隔。仅保留最新完整候选，历史数量不会累计占用解压候选集容量。
- 刷新页面恢复原内存任务尚未实现：新页面需重查，不会自动执行原查询；当前 16 页面/会话、64 会话与 60 分钟空闲释放见部署说明。不能将这项标记为方案全量验收通过。
- 未部署、未改服务器配置、未连接数据库、未 commit/push。原交接目录及 ZIP 保留。
