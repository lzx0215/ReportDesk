# ReportDesk Web 本地交付与部署说明

适用：单 IIS 站点、内网少量用户。使用现有 .NET Framework 4.8/Core；桌面程序保留。本说明不代表目标服务器已经验收。

若包名包含 `net462`，请优先阅读随包 `Web-net462-Compatibility.md`：该包要求 .NET Framework 4.6.2 或更高，不要求升级到 4.8，其余权限、配置和业务验收要求不变。

## 构建

在仓库根目录运行 `powershell -NoProfile -File scripts/build-web.ps1`。输出新的 `artifacts/web/ReportDesk-Web-时间/` 完整网站包及 SHA256 清单，不覆盖旧包，不配置 IIS。

发布包默认离线，自动同步关闭，维护白名单为空。不能只替换 DLL 就视为完成发布；网站包含 bin、UI、Web.config、Global.asax 和说明。构建脚本会把生成的依赖绑定重定向合入网站 Web.config；不要用源码中的 Web.config 直接覆盖已打包配置。

## 服务器准备（现场执行，不是构建脚本自动操作）

1. 备份现有 IIS 配置及本程序旧包，确认维护窗口。保留既有 80/8080/8081 网站和绑定。
2. 核实 .NET Framework 4.8、IIS ASP.NET 4.x 功能。新增一个独立 x64 应用池，CLR v4.0、Integrated、一个工作进程；加载用户配置文件，以验证服务账号 DPAPI。此版本不是 ASP.NET Core，不需要它的 Hosting Bundle。
3. 新建网站指向完整发布目录，使用可信的院内 HTTPS 和批准网段。如需无人访问时持续运行，可配置应用池 AlwaysRunning、网站 preloadEnabled 及已安装的 Application Initialization，并在现场验证；停 IIS 期间不会清理临时工作区，重启后检查可回收的遗留目录。
4. 在站点之外准备固定数据目录，例如 `C:\ReportDeskData`，存放连接配置、日志及本机 XML 的临时工作区。`ReportDesk.ServerReportsEnabled` 未配置时默认为 `false`：启动不依赖服务器 LIB，不扫描服务器报表目录，也不启动 HIS 发布同步。网站目录对应用身份只读；数据目录授予必要读写权限，不能映射为静态网站。本机 XML 原件及备份在用户电脑，上传的解析副本在数据目录中。开发知识库保持只读，本地检查使用隔离副本。
5. 编辑部署副本 Web.config 中 `ReportDesk.DataDirectory`。`MaintenanceAddresses` 为空时，院内打开网站即可使用查询和维护全部功能；若填写 IP，则仅这些电脑能做维护。
6. 入口为 `/`（查询与维护同一页）。先以 Offline=true，在“报表来源”选择本机目录副本和独立备份目录，检查条件、来源及编辑功能；本机模式的 SQL/XML 保存写回所选电脑目录，先用隔离副本测试。
7. 获准真实数据库测试后，才把 Offline 改为 false，在维护入口配置现场最小权限 Oracle 账号。密码只在服务器以运行账号 DPAPI 保存，或取消记忆仅进程内使用；应用回收后未保存密码要重新输入。更换服务身份时需重新配置，不复制开发电脑密文。
8. TNS 文件统一放在数据目录的 config 子目录内，并在 `ReportDesk.TnsFiles` 登记完整路径（分号分隔）。仅登记文件允许读取，不接受任意客户端路径。可不使用 TNS，直接配置主机/端口/Service Name。

部署配置不提交仓库。没有密码或端点信息应在现场填写，不发送到日志或文档。

更新包保留原 `Web.config` 和数据库连接配置字节。默认本机模式忽略旧 `ReportsDirectory=C:\LIB`，不要求该目录存在，也不创建替代的空 Reports 目录。默认关闭服务器报表并不改变 Offline、维护权限或数据库权限。

仅在明确需要旧服务器报表模式时，现场设置 `ReportDesk.ServerReportsEnabled=true` 并重启本应用。此时 `ReportsDirectory` 缺失或留空兼容 `DataDirectory\Reports`；显式路径不存在会停止启动。目录需有必要读写权限，先备份且避免 HIP 等其他程序同时写入。启动及“检查新增”扫描整个配置根目录，旧 `import-sources.json` 不会缩小扫描范围；根外记录保留但不加载。更换根目录使用独立同步状态，旧状态保留用于回退。

## 院内 HTTP

本机目录读写需要可信 HTTPS、安全上下文及支持目录句柄的浏览器；仅真实 loopback 本地调试允许 HTTP，院内 IP 的 HTTP 不能代替。服务器兼容模式的普通页面仍支持 HTTP；HTTP 会话 Cookie 不带 Secure，CSRF 与同源检查保留。`MaintenanceAddresses` 为空时维护权限向所有可访问客户端开放，请按现场授权配置。

## 自动更新报表

本节仅适用于显式设置 `ServerReportsEnabled=true` 的服务器兼容模式；默认本机模式不初始化、检查或写入旧服务器报表及同步状态，不显示服务器导入、发布与同步入口。

“检查新增”只扫描服务器现有文件，不从 HIS 下载，也不刷新已有定义。“同步状态 → 立即检查”及后台轮询才读取发布库。当前读取 `HIS.SYS_UPDATE_RELEASE`（说明前缀“一键发布配置信息”）和 `HIS.SYS_UPDATE_RELEASE_FILE`；其他主机须通过该发布途径提交完整报表及配套 XML。只修改那台主机的本地文件不会同步过来。

下载的必要条件是 `ServerReportsEnabled=true`、`Offline=false`、`SyncEnabled=true`、`SyncSampleValidated=true`，并且连接配置、服务账号解密、发布表只读权限有效。样本校验通过后才能设置 `SyncSampleValidated=true`，不能用该开关跳过验证。服务器模式页面会提示离线、同步关闭或未校验的阻塞。新包仍默认离线、同步关闭，不擅自连接真实 Oracle。

需要发布表的批准只读权限。先用已有发布样本验证 owner/字段、目录标志、压缩格式和解压后的 XML 哈希；不是为了测试再发布到全院。完成后才设置 `SyncSampleValidated=true` 和 `SyncEnabled=true`，默认每 30 秒检查，可调整 `SyncSeconds`。代码不会启动 HIP，也不会写发布表。

同步只处理可识别报表及其必要模板，不能用来更新整个 HIS 客户端。发布不完整、路径不安全、本地编辑冲突均停止对应批次；不因一次失败清空目录，不执行包内程序。暂存恢复文件仅为批次故障恢复，不是长期报表版本库。维护页显示同步状态，可立即检查。

首版每轮仍读取并校验所选历史发布 BLOB，没有实现仅元数据轮询缓存。历史多时需先测读取量与耗时，再设置启用后的 `SyncSeconds`，不能直接承诺 30 秒同步完成。最新完整候选替换较旧候选，不会把全部历史解压内容堆在内存中。超出压缩包/候选集安全容量会明确失败，不静默跳过；这些限制不作用于查询结果。

后台在启动后先检查一次，此后每轮完成后等待 `SyncSeconds`（默认 30 秒）；繁忙时可能延后。发布成功下载并校验后，程序自动重载定义；已打开网页每 10 秒检查目录版本，空闲且没有弹窗时更新列表，保留已有条件与结果，使用新定义需重新选择报表。不会自动重跑 SQL。隐藏页面恢复可见时补查。

无人访问时也要下载：安装 IIS Application Initialization，将本程序池（现场为 `ReportWeb`）设为 `AlwaysRunning`、空闲超时 `00:00:00`，网站应用设 `preloadEnabled=true`；只调整本程序，不执行全局 iisreset。停池/停站期间不能同步，重新启动后补查。须现场关闭所有浏览器、发布一份已获准的更新，核对 LIB 文件哈希及同步状态，不能用“打开网页后才更新”代替常驻验收。[Microsoft 应用预加载说明](https://learn.microsoft.com/en-us/iis/configuration/system.webServer/applicationInitialization/)

网页保存只修改本程序副本并重载，不代表已发布回 HIS。不要让 HIP 或其他复制程序与本程序同时更新同一 Reports 目录。

## 设置、多个数据库连接与导入

左侧齿轮打开数据库连接设置。默认本机模式仅显示 **数据库连接**；显式启用服务器报表后才显示 **HIS 发布同步** 页签和顶部“同步状态”。切换页签保留尚未保存的连接输入；同步操作不会保存或测试数据库连接。本机目录操作集中在左侧文件夹 **报表来源** 中，编辑器“本机保存状态”也直接进入该窗口。

在数据库页签选择已保存连接，或点击 **新增连接** 填写另一组 Oracle 配置。**保存连接** 不连接数据库；**测试并保存** 仅在测试成功后保存，测试不验证报表权限。新增或编辑非当前连接不会改变正在使用的连接；点击 **设为当前连接** 并确认后才切换。修改当前连接并保存会沿用原行为，作用于后续查询。

当前连接由同一服务器应用进程内的查询与已启用的 HIS 发布同步共用，不是每个浏览器单独选择数据库。切换前核对目标库是否适合已有查询及同步；正在执行的查询使用启动时的连接，同进程新操作读取当前连接。当前页面切换连接后清除已有查询结果。多 IIS worker 或多个实例之间没有实时切换广播；保存前会检查配置是否已被其他进程修改并拒绝过期覆盖，重新打开设置可刷新档案，但这不等于跨实例查询已同步切换。

各连接独立保存密码；新增连接不会沿用其他连接的密码。勾选保存时沿用服务器运行账号的 CurrentUser DPAPI 加密；不勾选时仅保留在服务进程内，IIS 回收后需重新输入。浏览器不持久化密码，接口不返回明文或密文。

旧单连接 `connection.json` 自动兼容，首次保存时以一次原子替换写入活动连接及多连接列表。根层保留旧版本可读取的活动连接字段。回退程序前备份数据目录中的 `connection.json`；旧版本若再保存配置，会丢失新增的连接列表，恢复新版时需使用备份。代码升级前的现有配置也应备份。本地开发与离线检查不修改现场配置。

左侧原“＋”与“文件夹”统一为 **报表来源**：

- **打开本机目录**：选择本机报表目录与独立备份目录，点击“使用此目录”；SQL/XML 修改写回当前电脑，保存前先备份。全部 XML 仍需发送到服务器独立工作区解析。
- **导入到服务器**：仅在 `ServerReportsEnabled=true` 时显示。选择 XML 文件或文件夹，上传副本到服务器公共报表库；后续修改保存在服务器，不写回本机原文件。文件夹会批量识别 XML 并匹配配套版式。

默认模式关闭当前本机目录后显示空列表，等待重新选目录；不会回退到旧 LIB。服务器模式下，切换页签不会切换实际来源；进入“导入到服务器”后需明确点击 **切回服务器目录** 并确认，才开放服务器导入。未完成的本机保存和编辑草稿仍会阻止切换。目录操作不会读取、保存或测试数据库连接。原有文件大小、数量限制及 XML 识别规则保持不变。

## 导出报表 SQL

在有维护权限的网页点击“导出 SQL”，按报表名称搜索后点击对应行的“导出”；也可勾选多张报表后导出所选，或选择“导出全部报表 SQL”。搜索变化时已勾选的报表仍保留，同名报表以报表 ID 区分。单张导出的文件以报表名称命名，不能用于文件名的字符会被替换；多张及全部导出使用统一文件名。浏览器下载 UTF-8 文本文件，内容按“报表名：”换行接原定义中的查询 SQL 排列；多个查询数据源分别标明。导出读取当前来源已加载并校验的 XML：本机模式为本页临时副本，服务器模式为配置报表目录；不执行 SQL、不代入参数，也不包含条件选项数据源的 SQL。下载文件包含报表定义，请按现场要求保管。

## 结果、取消与容量

查询/选项/导出只保存在服务器内存。每个页面按自身活动时间独立计时，默认空闲 60 分钟释放，可改 `IdleMinutes`；操作另一个页面不会保活旧页面，正在执行的任务不会因空闲计时清除。可见本机页面的真实鼠标/键盘操作会节流续期，本机物理文件写入期间每 30 秒尽力续期；普通空闲页面没有保活轮询。

关闭或离开页面会尽力通知服务器释放；运行中任务或未决本机保存不立即释放，之后按空闲规则处理。通知丢失、浏览器异常退出或 IIS 回收时不能保证立即删除。服务器定期重试清理属于本程序的已退出 worker 遗留目录，不处理活动 worker、未知目录或链接；文件占用造成的失败会留待后续重试。本机原 XML、备份及浏览器 IndexedDB 保存恢复记录不随服务器清理删除。工作区过期后保留编辑草稿与恢复记录，先核对本机保存状态，再重新加载目录。

刷新页面创建新上下文，需重新选择目录和查询；不会自动恢复或重跑原任务。每会话最多 16 个页面上下文，默认最多 64 个会话；达到限制会提示，不清掉正在运行的任务。IIS 回收后内存结果丢失需重查。不要在服务器共享同一浏览器会话来模拟两个独立使用者。

默认最多 3 个同时处理的操作，忙时提示稍后重试，可配置 `MaxConcurrentOperations`。这不是 SQL 超时或结果行数上限，不返回截断结果。大报表和导出仍需现场看内存占用；不能据此承诺任意大查询。Excel 使用原格式容量限制，下载生成完毕才提供文件。

## 验证与回退

- 本地 HTTP 安全检查：构建并运行 `tests/ReportDesk.Web.Checks`，不连接数据库。`--serve <网站包绝对路径> <隔离数据目录绝对路径>` 只开启 localhost:18765 的离线预览，不是 IIS 验收。
- 两个浏览器分别查询/取消/翻页/导出，同浏览器两个标签也不能互相覆盖；普通来源不能直接调用维护接口。
- 用真实 LIB 的隔离副本验证 SQL 回读和列同步（字段描述需获准 Oracle），包括 SQL 已保存后再补齐模板。
- 仅服务器兼容模式：自动同步现场验证一份完整发布，无需打开服务器 HIP，更新文件并重载；再验证断网恢复、文件冲突、应用重启补查。业务结果需与 HIS 同条件核对。
- 升级时停止接新任务，告知执行中任务可能中断，备份目标应用、配置及将变动的报表，再替换完整包。出错时切回旧包；报表文件若已改变须另外恢复，程序回退不撤销 XML 修改。不修改或回滚 HIS 数据库。
- 本次固定更新包按 `Web-LocalXml-Update-20261106.md` 执行：保留旧 LIB 完成更新和健康验收，再自行决定是否移走；回滚到依赖 LIB 的旧版本前先恢复原目录及权限。安装器不删除、备份或恢复 LIB 内容，不跳过旧站点健康门禁。
