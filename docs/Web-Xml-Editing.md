# 网页编辑报表 XML

维护页面选中报表后点击“XML 编辑”，可选择查询设置、主报表设置或明细报表设置。模板由服务器按现有关联定位；关联不唯一或没有对应模板时停止，按名称匹配的候选模板须由维护人员确认归属。浏览器不能指定服务器文件路径。

编辑前核对页面显示的服务器目标路径并自行备份。修改后可点击“检查 XML”，再点击“保存到服务器”并确认。系统校验 XML 格式、根元素、编码与源文件是否变化；查询设置须是 `ReportQueryInfo`，报表模板须是 FarPoint `Spread`。不连接数据库，也不验证 SQL、数据绑定、HIS 显示和打印效果。保存成功后按现有事务重新加载报表；修改模板不自动更改查询结果和 Excel 列名，也不自动发布回 HIS。

保持原文件编码和 BOM；统一换行会保持原样。原文件存在混合换行或无法无损识别编码时停止保存。系统编辑请求受现有 8 MiB HTTP 请求限制；文件内容和 JSON 编码后的请求总大小超过限制时不能保存。保存不会创建可长期保留的备份。其他程序应避免同时编辑同一文件，检测到未知外部变更时停止恢复、保留文件与恢复标记，需由维护人员排查；不能认为现有文件锁能阻止所有外部程序。

“同步报表列”仍有独立的模板限制，此功能允许直接编辑完整 XML，不代表所有报表结构或 SQL 改动均已适配。测试应在副本上进行，再由现场确认目标文件、备份、回退及 HIS 行为。
